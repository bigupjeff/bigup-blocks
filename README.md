# Utility Blocks

> A collection of custom Gutenberg blocks for layout, UI components, and interactive features in WordPress.

---

## ✨ Features

- Collection of reusable Gutenberg blocks for various use cases
- Includes layout utilities, UI components, and interactive elements
- Built for flexibility and experimentation
- Designed to extend the WordPress block editor
- Lightweight and modular block structure

Included blocks:

- Anchor — wrap anything in a link (HTML anchor)
- Border — enhanced border and layout control
- Camper Animation — animated visual component
- Flippable Card / Cards — interactive card UI elements
- Hero Punch — prominent hero section block
- Inline SVG — Display SVG inline to allow manipulation with CSS/JS
- Mortgage Calculator — interactive calculation tool
- Social Links (Gradient Fill) — enhanced social icon styling
- Vector Shapes — decorative and layout graphics

---

## 📦 Installation

### WordPress

1. Upload the plugin to `/wp-content/plugins/`
2. Activate the plugin via the WordPress admin
3. Open the block editor to access the custom blocks

---

## 🚀 Usage

### WordPress

- Open the block editor in any post or page
- Search for the desired block by name
- Insert and configure using block settings

Use cases:
- Enhancing content with interactive UI elements
- Adding custom layout and design components
- Extending core block functionality

---

## ⚙️ Configuration

- Configure individual blocks via block settings in the editor
- Some blocks may include custom controls or options
- No global configuration required
